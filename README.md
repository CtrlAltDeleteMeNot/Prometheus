# Prometheus

Prometheus is an open-source cryptocurrency market screener that supports multiple exchanges and is distributed as a Progressive Web App (PWA).

🌐 **Live application:** https://ctrlaltdeletemenot.github.io/Prometheus/

## Features

- Multi-exchange cryptocurrency screening
- Progressive Web App (PWA)
- Open source
- Fast client-side interface

## Getting Started

### Prerequisites

- Node.js
- npm

Install dependencies:

```bash
npm install
```

## Development

Build and run the project:

```bash
npx gulp
```

## Testing

Run the test suite:

```bash
npx jest
```

## Publishing

Build and publish the application:

```bash
npx gulp all
```

## Downloading Assets

Download the required assets:

```bash
npm run download
```
